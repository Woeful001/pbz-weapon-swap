# PBZ Weapon Swap

《影之刃零》(Phantom Blade Zero) 的 UE4SS Lua 模组：把游戏**原生的切换键**（键盘 `1` / `2`、手柄十字键）改成「按拼音顺序换上武器池里的下一把」。

- **两套武器都能管**：主武器（原生 `1` / 十字键左）、影之武装（原生 `2` / 十字键右），各自独立开关与武器池
- 一次按键 = 一次切换：原生换武器动作（含配套的换武器技能）完整播放，不是「先切一把再补一刀」
- 三种模式：关闭 / 循环 / 随机，`F9` 打开设置菜单，**首行选改哪一套**，下面才是它自己的模式与勾选池
- **切换冷却开关**：菜单里一行复选框，勾上则由模组在每次切换后清掉游戏的武器冷却，不勾则完整保留原生冷却
- 排序取游戏数据表里的中文武器名，按完整拼音升序（首字母分组，组内按全拼），可循环
- 目标武器在副手 → 直接与主手交换；不在装备栏 → 自动换装进副手槽再切过去
- 改的是数据层槽位，不经过技能/输入判定，因此不受入战状态影响
- `F9` 菜单里状态分三行显示（当前目标 / 主武器 / 影之武装），另有「刷新武器列表」按钮，把新获得的武器收进池子
- 界面语言跟随游戏语言（中文 / English），也可在菜单或 `config.txt` 里手动指定

## 安装

1. 游戏装好 **UE4SS 4.0.0（UE5.7 版）**，确认 `PBZ\Binaries\Win64\ue4ss\` 下有 `UE4SS.dll` 与 `Mods\`
2. 把压缩包里的 `PBZWeaponSwap` 整个文件夹放到 `PBZ\platform\steam\ue4ss\Mods\`
3. 启动游戏；`F9` 能弹出菜单即安装成功

> 4.5.0 起不再包含自选面板（`pickpanel.lua`），包里只有 `main.lua` 与 `vendor/`。

## 按键

| 按键 | 作用 |
| --- | --- |
| `1` / 手柄十字键左 | 游戏原生切换主武器（模组接管后换成池里的下一把） |
| `2` / 手柄十字键右 | 游戏原生切换影之武装 |
| `F9` | 打开 / 关闭设置菜单 |
| `F2` | 恢复安装时的原始装备（读取 `snapshot.txt`） |
| `ESC` | 关闭菜单 |

`F9` 菜单：首行「配置目标」选择主武器 / 影之武装，下面依次是模式、切换冷却开关、武器勾选池、刷新列表、恢复原始装备。
菜单打开时进背包会自动关闭（两套 UMG 同时抢输入会崩）。

## 配置文件 `config.txt`

放在模组根目录（`Mods\PBZWeaponSwap\`），改完重启游戏生效。

```
version=4.5.0
lang=auto          # auto / zh / en
target=main        # F9 首行默认选中哪一套
cd=0               # 1 = 保留游戏原生冷却；0 = 模组切换后立即清冷却
main.mode=cycle    # off / cycle / random
shaqi.mode=cycle
main.pool=FangHuaXieShan,SnakeDual   # 省略 = 全部武器
```

- `main.pool` / `shaqi.pool` 用逗号分隔武器 id；留空表示全选
- `cd` 是全局开关（组件冷却两套共用），菜单里勾选后自动写回
- 旧配置里的 `main.cmode` / `main.random` 会被自动迁移成 `mode`

## 工作原理

| 环节 | 做法 |
| --- | --- |
| 接管按键 | 钩 `PBZBackPackSubsystem:SetCurrentWeaponByIndex`，识别「切到相邻槽」的原生调用 |
| 选下一把 | 读 `GetAllNormalWeapons` / 装备槽，按中文名的拼音排序后用模组自己的游标推进 |
| 预置 | 空闲时用 `ReplaceWeaponByIndex` 把下一把放进待切槽，按键时原生直接切出来，技能不被截断 |
| 切换 | 让游戏自己跑 `SetCurrentWeaponByIndex`，冷却按 `cd` 开关决定是否清零 |
| 恢复 | `snapshot.txt` 记录安装时的两套装备，`F2` 或菜单按钮一键还原 |

## 版本历史

**4.5.1**

- 修复「全选 / 取消全选」：池子被清空（一个都没勾）时按钮曾把自己当成“已全选”，于是取消之后怎么点都只是继续取消，现在会正确判断并把整池勾回来
- 修复点「刷新武器列表」或连续点菜单时 UE4SS 崩溃：重建菜单控件原本在按钮回调里同步执行，会销毁正在派发点击的那个控件；现在统一推迟到回调之外，并且一次操作只重建一次（两个分组之间隔 120ms），菜单关闭时则留到下次打开再重建

**4.5.0**

- 优化了 UI：设置菜单重排（目标 → 模式 → 冷却 → 武器池 → 操作按钮），状态行分三行显示当前目标与两套武器的持有情况，武器列表按拼音排序并标注序号
- 新增开关武器冷却功能：菜单里一个复选框即可在「保留原生冷却」与「切换后立即清冷却」之间切换，配置写入 `config.txt` 的 `cd=`
- 移除了自选（暂停弹面板选武器）实验功能与随附的单槽逻辑，包内不再带 `pickpanel.lua`；只保留稳定可用的 关闭 / 循环 / 随机 三种模式
- 钩子、快照、背包互斥、切图保护沿用 4.1 起的稳定实现

**4.1.0**

- 菜单支持「自定义池」：逐把勾选参与轮换的武器，配置写进 `config.txt`
- 状态三行 + 刷新武器列表按钮；`F2` 恢复原始装备

**4.0.0**

- 重写为「原生技能 + 数据层预置」：按键交给游戏自己走完整换武器流程，模组只负责决定切哪一把
- 支持影之武装（`SetCurrentWeaponByIndex(idx, false)`）与两套独立模式

**3.1.0 / 3.0.0**

- 加入随机模式与设置菜单（F9），界面支持中英双语

**2.0.0**

- 初版：按 `1` 循环切换主武器，直接调 `SetCurrentWeaponByIndex`

## 已知限制

- 冷却开关清的是 `CharacterWeaponsComponent` 的共享冷却，两套武器共用一个计时
- 只在单机使用；联机/云存档同步未验证
- 改的是内存里的装备槽，重进存档后回到存档里的装备（`F2` 也依赖 `snapshot.txt`）
