PBZWeaponSwap 2.0  ——  影之刃零：用游戏原生切换键按拼音顺序换上任意主武器
=====================================================================

做了什么
  原版的主/副武器切换键（键盘 1、手柄十字键）在本模组下不再只是「手上这两把
  互换」，而是按你的设置换成武器池里的下一把：手上直接出现新武器，原生那一次
  换武器动作（含配套的换武器技能）照常完整播放，不是「先切一把再补一刀」。

热键
  1（键盘数字 1）/ 手柄十字键左   切换武器（原生键，未改绑定）
  F9                              打开设置菜单（四种模式 + 自定义武器池）
  F2                              恢复首次使用 mod 时记录下的原始装备

菜单（F9）
  模式：
    关闭    完全不干预，恢复原版两把互换的手感
    循环    按拼音顺序在全部已拥有武器里轮换，最后一把之后回到第一把
    随机    每次随机换到另一把（不会连着换到同一把）
    自定义  只在下面勾选的武器里轮换
  自定义池：
    25 个武器复选框，勾掉的不参与循环/随机；全部取消勾选时自动回退到全部武器
    「自定义池内随机顺序」勾上后，自定义模式也走随机而不是拼音顺序
  恢复原始装备：
    等同于按 F2
  设置保存在 Mods/PBZWeaponSwap/config.txt，下次进游戏自动读回。

排序规则
  取游戏数据表里的中文武器名，按完整拼音（无声调）升序排列，同名按武器 ID。
  当前 25 把的顺序：
    白蟒赤练 / 白山风雷剑 / 白影 / 别离残钩 / 残钢刃 / 长形黑伤 / 痴者残剑 /
    刺骨混沌 / 荡寇凶刃 / 断肢锯 / 黑伤 / 黑伤双刃 / 红妆鬼斩 / 灵蛇软剑 /
    乱莺剑 / 木制黑伤 / 破军 / 圣母邪扇 / 天煞双钺 / 天玄青铜剑 / 亡命斩马刀 /
    偃月刀 / 妖锯 / 玉双环 / 紫冥剑

实现要点
  1) 钩住 UPBZBackPackSubsystem:SetCurrentWeaponByIndex。游戏按原生键时必然
     调用它，参数是「要切到的那个槽」（0/1）。
  2) 命中时不取消原生调用，而是把「下一把目标武器」写进那个槽
     （ReplaceWeaponByIndex(目标, 槽位)），让原生这一次切换直接把新武器拿到手上。
  3) 平时（距上次切换 ≥1.5 秒且不在换武器过场中）由后台把下一把预置到副手槽，
     所以按键时槽里已经是目标武器，连 ReplaceWeaponByIndex 都不需要，动作不会被
     打断。
  4) 循环位置用模组自己的游标，不依赖 CurrentWeaponIndex/CurrentMainWeaponID
     （这两个值在切换后有延迟），因此不会卡在同一把或在小范围里打转。
  5) 改的是数据层槽位，不经过技能/输入判定，所以不在战斗状态也能换。

注意
  · 这个 mod 会真的改写存档里的两个主武器槽（不是临时效果）。一直用下去，
    装备栏会随着循环变化；F2 可以一次性恢复到第一次使用时的状态。
  · 快照文件：Mods/PBZWeaponSwap/snapshot.txt；删掉它，下次会以当时的装备重新记录。
  · 日志：Mods/PBZWeaponSwap/log.txt，想关掉就把 main.lua 顶部的 DEBUG 改成 false。
  · 需要 UE4SS（本模组在 UE4SS v3.0.1 Beta 上开发验证）。
  · Scripts/vendor 内是第三方库：ModMenu（mattdavida/ue4ss-ModMenu, MIT）、
    UEHelpers（UE4SS 社区版, MIT），仅为菜单界面与取玩家控制器服务。
