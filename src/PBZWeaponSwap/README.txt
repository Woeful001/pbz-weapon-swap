PBZWeaponSwap 4.1.0  ——  影之刃零：用游戏原生切换键按拼音顺序换上武器
=====================================================================

做了什么
  原版的主/副武器切换键（键盘 1 / 2、手柄十字键左右）在本模组下不再只是「手上
  这两把互换」，而是按你的设置换成武器池里的下一把：手上直接出现新武器，原生那
  一次换武器动作（含配套的换武器技能）照常完整播放，不是「先切一把再补一刀」。
  主武器与影之武装两套各自独立设置。

热键
  1（键盘数字 1）/ 手柄十字键左   切换主武器（原生键，未改绑定）
  2（键盘数字 2）/ 手柄十字键右   切换影之武装（原生键，未改绑定）
  F9                              打开设置菜单
  F2                              恢复首次使用 mod 时记录下的原始装备

菜单（F9）
  状态区（三行，随手能看到现在拿的是什么）：
    当前目标：主武器
    主武器：长形黑伤（循环）
    影之武装：巨凶斧（循环）
    池：全部 25 把   或者   12 / 25 把
  目标：
    主武器 / 影之武装 —— 首行，决定下面这些设置在改哪一套
  模式（对当前目标生效）：
    关闭    完全不干预，该套武器恢复原版两把互换的手感
    循环    按拼音顺序在全部已拥有武器里轮换，最后一把之后回到第一把
    随机    每次随机换到另一把（不会连着换到同一把）
    自定义  只在下面勾选的武器里轮换
  自定义池：
    当前目标那一套的武器复选框，勾掉的不参与循环/随机；全部取消勾选时自动回退
    到全部武器。切换目标时池子会跟着换，勾选状态保留。
  「自定义池内随机顺序」勾上后，自定义模式也走随机而不是拼音顺序。
  刷新武器列表：新获得武器后点一下，重新读取两套武器并重建勾选池（勾选状态保留）。
  恢复原始装备：等同于按 F2。
  界面语言：自动（跟随游戏语言）/ 中文 / English。
  说明区（四行，每行一条模式规则）：
    主武器：键盘 1 / 手柄十字键左
    影之武装：键盘 2 / 手柄十字键右
    关闭：完全不干预，保持游戏原生行为。
    循环：按中文名拼音顺序轮换，走完池里所有武器再回到第一把。
    随机：每次换到池里另一把，不会连续两次拿到同一把。
    自定义：只在勾选的武器里按上面的顺序 / 随机规则切换。
  设置保存在 Mods/PBZWeaponSwap/config.txt，下次进游戏自动读回。

界面语言
  默认跟随游戏语言：读游戏当前的语言代码，zh 开头走中文，其余走英文。
  想固定语言：菜单里选「界面语言」，或在 config.txt 写 lang=zh / lang=en
  （lang=auto 为跟随游戏语言）。切换语言后菜单立即重建，不需要重启。

实现要点
  1) 钩住 UPBZBackPackSubsystem:SetCurrentWeaponByIndex。游戏按原生键时必然
     调用它，参数是「要切到的那个槽」（0/1）和 IsNormalWeapon（true 主武器、
     false 影之武装），靠它区分两套。
  2) 命中时不取消原生调用，而是保证那个槽里就是「下一把目标武器」
     （ReplaceWeaponByIndex(目标, 槽位) / ReplaceShaqiWeaponByIndex），让原生
     这一次切换直接把新武器拿到手上。
  3) 平时（距上次切换 ≥1.5 秒且不在换武器过场中）由后台把下一把预置到副手槽，
     所以按键时槽里已经是目标武器，动作不会被插入打断。预置过的那把在玩家按键
     之前不会被换掉，随机模式因此也不会在后台乱换装备。
  4) 循环位置用模组自己的游标，不依赖 CurrentWeaponIndex/CurrentMainWeaponID
     （这两个值在切换后有延迟），因此不会卡在同一把或在小范围里打转。
  5) 改的是数据层槽位，不经过技能/输入判定，所以不在战斗状态也能换。

注意
  · 这个 mod 会真的改写存档里的武器槽（不是临时效果）。一直用下去，装备栏会
    随着循环变化；F2 可以一次性恢复到第一次使用时的状态。
  · 快照文件：Mods/PBZWeaponSwap/snapshot.txt；删掉它，下次会以当时的装备重新记录。
  · 日志：Mods/PBZWeaponSwap/log.txt，想关掉就把 main.lua 顶部的 DEBUG 改成 false。
  · 需要 UE4SS（本模组在 UE4SS v3.0.1 Beta 上开发验证）。
  · Scripts/vendor 内是第三方库：ModMenu（mattdavida/ue4ss-ModMenu, MIT）、
    UEHelpers（UE4SS 社区版, MIT），仅为菜单界面与取玩家控制器服务。

版本历史
  1.0.0
    · 键盘 < 上一把、> 下一把：按武器中文名的拼音顺序循环，25 把主武器全遍历，
      首尾自动回绕。
    · 目标武器已在装备栏：直接切为当前主手，不做换装。
    · 目标武器不在装备栏：先自动换装进非当前槽，再切为当前主手（即与主手交换，
      另一只手拿的始终是你来的那把）。
    · 全程直接调用 UPBZBackPackSubsystem 的接口，不走武器技能链路，切换前重置
      武器切换冷却，因此不受是否入战限制。
    · F2 一键恢复进入游戏时的原始装备。
  2.0.0
    增加 UI 以及「关闭」「顺序」「随机」「自定义」选项。
  3.0.0
    增加切换影之武装的功能。
  3.1.0
    优化 UI（状态分三行显示，说明按两套武器分行），支持双语（界面语言跟随游戏
    语言，可手动指定），增加刷新功能（把新获得的武器加入列表）。
  4.0.0
    · 修复大地图传送后导致游戏崩溃：不再注册 LoadMap 前后钩子（多个 Lua mod 同时
      注册会在设置返回值这条路径上冲突），改为轮询世界对象地址判定切图，切图后
      冻结 10 秒再恢复。
    · 修复切换武器偶发不释放换武器技能：每次切换完成后立刻把下一把预置进副手槽，
      连按也能让原生换武器技能完整播放。

  4.1.0
    适配 UE4SS 4.x 装载器（3.0.1 → 4.0.0 的 Lua 绑定变更）：武器显示名改为内置
    名单，不再调用 GetMainWeaponTableData() 与 GetAllNormalWeapons()（4.x 下前者
    会让游戏直接崩溃、后者返回形态变化），武器切换与菜单逻辑不变。
