PBZWeaponSwap  ——  影之刃零：按「<」「>」按拼音顺序循环切换主武器
=====================================================================

热键
  <   (键盘 , 键 / OEM_COMMA)   上一把
  >   (键盘 . 键 / OEM_PERIOD)  下一把
  F2                             恢复首次使用 mod 时记录下的原始装备
  F11                            自检：连续 26 次“下一把”，日志里可看到是否遍历全武器
  F12                            把当前的排序表写进 log.txt

排序规则
  取游戏数据表里的中文武器名，按完整拼音（无声调）升序排列，同名按武器 ID。
  当前 25 把的顺序：
    白蟒赤练 / 白山风雷剑 / 白影 / 别离残钩 / 残钢刃 / 长形黑伤 / 痴者残剑 /
    刺骨混沌 / 荡寇凶刃 / 断肢锯 / 黑伤 / 黑伤双刃 / 红妆鬼斩 / 灵蛇软剑 /
    乱莺剑 / 木制黑伤 / 破军 / 圣母邪扇 / 天煞双钺 / 天玄青铜剑 / 亡命斩马刀 /
    偃月刀 / 妖锯 / 玉双环 / 紫冥剑

切换逻辑
  1) 当前主手武器在排序表里定位；
  2) 目标武器已装备在另一个槽 → 直接 SetCurrentWeaponByIndex 切过去（相当于主副手交换）；
  3) 目标武器不在装备栏 → ReplaceWeaponByIndex 把它换进“非当前”那个槽，再切过去。
     于是上一把会退到副手，往回按 < 时可以立刻换回来。
  4) 切换前调用 CharacterWeaponsComponent:ResetChangeWeaponCooldowns()，
     不走技能/输入链路，因此不受入战状态与切换冷却限制。

注意
  · 这个 mod 会真的改写存档里的两个主武器槽（不是临时效果）。一直用下去，
    装备栏会随着循环变化；F2 可以一次性把所有槽恢复到第一次使用时的状态。
  · 快照文件：Mods/PBZWeaponSwap/snapshot.txt；删掉它，下次按方向键时会以
    当时的装备重新记录。
  · 日志：Mods/PBZWeaponSwap/log.txt，想关掉就把 main.lua 顶部的 DEBUG 改成 false。
