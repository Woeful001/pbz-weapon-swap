PBZWeaponSwap 4.5.1
====================

《影之刃零》换武器模组：用游戏原生的切换键，按拼音顺序换上武器池里的下一把。

安装
----
1. 游戏装好 UE4SS 4.0.0（UE5.7 版），确认 PBZ\Binaries\Win64\ue4ss\ 下有 UE4SS.dll
2. 把 PBZWeaponSwap 整个文件夹放到 PBZ\platform\steam\ue4ss\Mods\
3. 进游戏按 F9，能弹出菜单就是装好了

按键
----
1          游戏原生切换主武器（模组接管后 = 池里的下一把）
2          游戏原生切换影之武装
F9         打开 / 关闭设置菜单
F2         恢复安装时的原始装备（snapshot.txt）
ESC        关闭菜单

模式
----
关闭       完全交给游戏，模组不介入
循环       池内按武器中文名的拼音顺序轮换
随机       池内随机，不会连续两次同一把

菜单（F9）
----------
首行「配置目标」选主武器 / 影之武装，下面依次是：
  模式          关闭 / 循环 / 随机
  切换冷却      勾上 = 模组在切换后立即清冷却；不勾 = 保留游戏原生冷却
  武器池        逐把勾选参与轮换的武器
  刷新武器列表  把新获得的武器收进池子
  恢复原始装备  等同 F2
状态区分三行显示：当前配置目标 / 主武器 / 影之武装。
菜单开着时打开背包会自动关闭菜单（两套 UMG 抢输入会崩）。

配置 config.txt
---------------
version=4.5.1
lang=auto          自动跟随游戏语言，也可写 zh 或 en
target=main        F9 首行默认选中哪一套
cd=0               1 = 保留游戏原生冷却；0 = 切换后立即清冷却
main.mode=cycle    off / cycle / random
shaqi.mode=cycle
main.pool=FangHuaXieShan,SnakeDual     逗号分隔武器 id，省略 = 全部武器

原理
----
· 钩 PBZBackPackSubsystem:SetCurrentWeaponByIndex，识别「切到相邻槽」的原生调用
· 空闲时用 ReplaceWeaponByIndex 把下一把预置到待切槽，按键时原生直接切出来
· 切换交给游戏自己跑，技能与动画完整播放
· 冷却按 cd 开关决定是否 ResetChangeWeaponCooldowns
· snapshot.txt 记录安装时的两套装备，F2 一键还原

已知限制
--------
· 冷却开关清的是组件共享冷却，两套武器共用一个计时
· 只改内存里的装备槽，重进存档回到存档里的装备
· 仅在单机环境验证
